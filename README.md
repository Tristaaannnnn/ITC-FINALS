# CarZone - Responsive Car Blog

A multi-page responsive web blog created for the ITC Introduction to Computing Midterm Hands-On Exam.

## Pages

- `index.html` - Home page
- `about.html` - About page
- `articles.html` - Four car articles
- `contact.html` - Contact page with a basic non-functional form
- `styles.css` - Shared external CSS
- `images/README.txt` - Image sources and attribution information

## Images

The project uses web-hosted images from Unsplash. This means you do not need
to manually download the pictures before uploading the project to GitHub.
The browser loads the images from their source URLs.

## How to Run

1. Upload all project files to a GitHub repository.
2. Open `index.html` in a browser, or enable GitHub Pages.
3. Test Home, About, Articles, and Contact.
4. Resize the browser window to test the responsive layout.

## GitHub Pages

Set GitHub Pages to deploy from the branch containing these files. The
`index.html` file is the website home page.
